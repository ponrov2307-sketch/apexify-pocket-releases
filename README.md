# Apexify Pocket — firmware releases

This repository hosts compiled firmware binaries only, published as GitHub
Releases. It does not contain source code — Apexify Pocket's OTA update
mechanism reads this repo's `releases/latest` API endpoint to check for and
download new firmware.

Release assets are named per board target (e.g. `apexify-firmware-cyd.bin`
for the Apexify Pocket / CYD hardware).
